# ANIMAGUS Project Summary

## Project Overview
ANIMAGUS is an AI-powered game marketing platform that provides a one-stop solution for global game marketing campaigns.

## Technical Architecture
- **Three-layer decoupled design**: Frontend DAL layer and backend Repository layer use interface abstraction for seamless Demo/Production mode switching
- **Frontend**: Vue 3.4 + TypeScript, Vite 5, TailwindCSS 3.4, Pinia state management
- **Backend**: FastAPI + Uvicorn, Pydantic v2, JWT authentication, dependency injection
- **Demo Mode**: Environment variable controlled - both frontend and backend can run in demo mode with mock data

## Key Features
- Project management
- Campaign management
- Creative/material management
- Real-time monitoring and dashboard
- Market analysis
- AI chat interaction for marketing insights
- Multi-platform connections (Meta, Google Ads, etc.)

## Project Structure
```
ANIMAGUS/
├── frontend/          # Vue3 monorepo with pnpm workspace
│   └── packages/
│       ├── main-app/  # Main Vue3 application (port 3010)
│       └── shared/    # Shared utilities and types
├── backend/           # FastAPI service (port 8010)
│   └── app/
│       ├── api/       # API routes
│       ├── services/  # Business logic
│       ├── models/    # SQLAlchemy models
│       └── schemas/   # Pydantic schemas
├── docs/              # Project documentation
└── html/              # HTML prototypes
```

## Quick Start
- **One-command deployment**: `./run_server.sh` (supports local/cloud modes)
- **Local mode**: Development with hot reload
- **Cloud mode**: Production deployment with multi-worker support
- **Stop services**: `./stop_server.sh`
