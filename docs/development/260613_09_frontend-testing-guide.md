## 🐛 常见问题

### 1. Plan 不显示

**可能原因**：
- Agent 判断任务太简单，使用 ReAct 模式
- System Prompt 没有正确生成

**解决方案**：
- 尝试更复杂的查询："帮我分析..."、"对比..."、"生成报告..."
- 检查后端日志：`tail -f logs/backend-dev.log | grep Plan`

### 2. Tool Call 不显示

**可能原因**：
- 后端未发送 `TOOL_CALL_*` 事件
- 前端事件处理器未触发

**解决方案**：
- 打开浏览器控制台（F12）
- 查看 Network → WS/EventStream
- 检查事件流

### 3. HITL 对话框不弹出

**可能原因**：
- 后端未实现 HITL 检测
- 操作未被识别为高风险

**解决方案**：
- 此功能需要后端 Skills 配合
- 当前版本可能不支持

### 4. 页面空白或报错

**可能原因**：
- 前端代码语法错误
- TypeScript 类型错误
- 依赖缺失

**解决方案**：
```bash
# 查看前端日志
tail -f logs/frontend-dev.log

# 重启前端
pkill -f "vite.*13003"
cd frontend && pnpm --filter main-app dev --host 127.0.0.1 --port 13003 --strictPort
```
