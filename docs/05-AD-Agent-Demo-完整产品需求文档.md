## 1. 产品概述

### 1.1 产品定位

**AD Agent** 是一个AI驱动的游戏广告投放自动化平台，通过对话式交互和智能Agent，帮助游戏发行商实现：

- 🎯 **智能分析**: AI自动分析市场热点和竞品素材
- 🎬 **素材生成**: ABC三段式游戏素材自动生成
- 📊 **智能投放**: Meta Nobid等游戏优化策略
- 🤖 **实时监控**: 每秒数据更新，AI自动优化

**Demo目标**: 展示完整产品价值链路，通过固定数据和模拟交互，让用户直观理解AD Agent如何通过AI自动化实现游戏广告投放的全流程。

### 1.2 核心价值

| 传统投放 | AD Agent | 提升 |
|---------|----------|------|
| 手动分析市场 | AI自动分析 | 效率 +80% |
| 素材外包制作 | AI自动生成 | 成本 -60% |
| 人工试错投放 | AI智能规划 | ROI +15% |
| 每天查看数据 | 实时监控+自动优化 | 响应 +95% |

### 1.3 Demo特点

✅ **固定数据**: 所有输入都展示固定的结果，无需后端
✅ **对话驱动**: 左侧对话+右侧执行，类似Manus
✅ **游戏优化**: 针对游戏场景深度优化（RPG、Boss战、Nobid等）
✅ **完整流程**: 4个页面展示完整投放闭环
✅ **丰富动画**: 加载、过渡、数字滚动等动画效果

### 1.4 核心链路

```
用户输入游戏描述
    ↓ (AI分析与思考动画)
AI展示热点分析 + 推荐方向
    ↓ (用户确认)
AI生成素材（模拟ABC三段式生成）
    ↓ (用户预览与选择)
配置投放计划（Meta Nobid策略）
    ↓ (AI智能规划)
生成投放方案
    ↓ (确认投放)
进入监控看板（实时数据更新）
    ↓ (AI检测异常)
AI给出优化建议（暂停低效素材+转移预算）
    ↓ (用户确认执行)
完成闭环，展示效果提升（ROI +20.5%）
```

## 2. 对话式交互架构

### 2.1 整体布局

采用 **左侧对话 + 右侧执行** 的双栏布局：

```
┌─────────────────────────────────────────────────────────────────┐
│  Header: AD Agent - 智能投放助手  |  步骤: 1/4  |  状态: 规划中  │
├──────────────────────────────┬──────────────────────────────────┤
│                              │                                  │
│  左侧：对话区域 (40%)        │  右侧：执行面板 (60%)            │
│  ┌──────────────────────┐    │  ┌────────────────────────────┐ │
│  │ 对话历史              │    │  │ 当前任务                   │ │
│  │ AI: 欢迎使用...       │    │  │ 进度 + 结果展示             │ │
│  │ User: 推广RPG游戏     │    │  │                            │ │
│  │ AI: 分析完成...       │    │  │ 可操作卡片/按钮             │ │
│  │                      │    │  └────────────────────────────┘ │
│  │ [输入框...] [发送→]  │    │                                  │
│  └──────────────────────┘    │                                  │
│                              │                                  │
└──────────────────────────────┴──────────────────────────────────┘
```

### 2.2 交互原则

1. **对话驱动**: 所有任务通过对话触发
2. **实时反馈**: 每步操作都有明确的状态反馈
3. **可视化展示**: 复杂数据用图表、卡片展示
4. **渐进引导**: 逐步引导用户完成投放流程
5. **智能建议**: AI主动发现优化机会

### 2.3 消息类型

| 类型 | 用途 | 示例 |
|-----|------|------|
| 用户消息 | 用户输入描述 | "我要推广一款RPG游戏..." |
| AI消息 | AI分析和建议 | "分析完成！发现以下机会..." |
| 系统消息 | 状态通知 | "投放计划已创建成功！" |
| 任务更新 | 执行进度 | "正在生成素材... 60%" |
| 结果通知 | 结果展示 | "优化完成！ROI提升20.5%" |
| 异常预警 | 问题提醒 | "⚠️ CPA超目标20%" |

interface ProgressBarProps {

export const ProgressBar: React.FC<ProgressBarProps> = ({

  duration = 3000,

      />
    </div>
  );
};

#### 数字滚动组件

```tsx
import { useEffect, useRef, useState } from 'react';

interface AnimatedNumberProps {
  value: number;
  duration?: number;
  prefix?: string;
  suffix?: string;
}

export const AnimatedNumber: React.FC<AnimatedNumberProps> = ({
  value,
  duration = 1000,
  prefix = '',
  suffix = ''
}) => {
  const [displayValue, setDisplayValue] = useState(0);
  const startTimeRef = useRef<number>();
  const startValueRef = useRef(0);

  useEffect(() => {
    startTimeRef.current = performance.now();
    startValueRef.current = displayValue;

    function animate(currentTime: number) {
      const elapsed = currentTime - startTimeRef.current!;
      const progress = Math.min(elapsed / duration, 1);
      const easeOutQuart = 1 - Math.pow(1 - progress, 4);
      const currentValue = startValueRef.current + (value - startValueRef.current) * easeOutQuart;
      setDisplayValue(currentValue);

      if (progress < 1) {
        requestAnimationFrame(animate);
      }
    }

    requestAnimationFrame(animate);
  }, [value, duration]);

  return (
    <span>
      {prefix}{Math.round(displayValue).toLocaleString()}{suffix}
    </span>
  );
};
```
