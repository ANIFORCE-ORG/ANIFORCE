# v0.2 客户交付演示脚本

## 1. 演示目标

展示系统可以按真实业务流程交付：

```text
客户确认合作 -> 系统账号 -> 项目管理 -> 绑定投放账户 -> 项目下创建计划 -> 选择/上传素材 -> 填写素材标题描述 -> 创建计划 -> 上传投放结果 -> AI 复盘 -> 人工确认建议
```

## 2. 演示数据

项目：

- 客户A 短剧投放验收测试

广告账户：

- Meta Sandbox Ad Account

素材：

- 客户A_短剧反转结尾素材

计划：

- Day2_Meta_Test_1

## 3. 演示步骤

### Step 1：登录和项目

进入系统后打开项目管理，选择“客户A 短剧投放验收测试”。

说明口径：

- 项目是客户交付的业务容器。
- 项目下包含预算、周期、负责人、广告账户、计划、素材和复盘建议。

### Step 2：绑定广告账户

在项目详情查看已绑定的 Meta Sandbox Ad Account。

说明口径：

- 当前版本支持 Meta 沙盒/测试账户链路。
- Google/TikTok 作为待接入渠道展示，不作为本轮真实执行链路。

### Step 3：从项目创建计划

点击“新建广告/计划”，系统进入项目上下文创建流程。

检查点：

- 项目已自动带入。
- 选择 Meta。
- 选择广告账户。
- 配置目标、预算、周期、定向。

### Step 4：选择素材并填写绑定信息

选择素材后，在创建页填写：

- 计划内素材标题。
- 计划内素材描述。
- 投放文案。

说明口径：

- 同一个素材在不同计划下可以有不同标题、描述和投放文案。
- 系统保存的是计划-素材绑定元数据，不污染素材库原始素材。

### Step 5：创建计划

提交后回到项目详情。

检查点：

- 项目下出现新计划。
- 计划详情能看到绑定素材、标题、描述和投放文案。

### Step 6：上传投放结果

上传一条合法结果：

```json
{
  "impressions": 5000,
  "clicks": 240,
  "conversions": 12,
  "installs": 6,
  "spend": 90,
  "revenue": 130
}
```

说明口径：

- 系统会计算 CTR、CVR、CPA、CPI、ROI。
- 超过计划预算的结果会被拒绝，避免复盘数据失真。

### Step 7：AI 复盘和 Agent 建议

生成 Agent 建议或调用 AI 复盘摘要。

说明口径：

- AI 输出是草稿或建议。
- 所有真实投放动作必须人工确认。
- 系统记录模型 token 消耗、调用场景、模型和成本。

## 4. 客户验收口径

验收通过条件：

- 能从项目下创建计划。
- 能绑定广告账户。
- 能选择/上传素材。
- 能保存计划内素材标题和描述。
- 能上传投放结果。
- 能生成复盘建议。
- AI 调用可审计、可限额。
