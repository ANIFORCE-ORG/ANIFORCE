## 2. 本次交付范围

已纳入：

- Vue3 前端主应用。
- FastAPI 后端服务。
- SQLite POC 数据库。
- 项目、广告账户、素材、Campaign、报表、Agent 行动队列主链路。
- Meta 沙盒账户和 Meta Campaign ID 回写演示链路。
- 客户预览数据重置脚本。
- 部署配置清单、运行运维手册、权限说明、数据库交付说明、演示脚本、技术债清单。

不纳入 v0.1 验收：

- Meta Ad Set / Creative / Ad 完整创建链路。
- Google Ads / TikTok Ads 真实 API。
- 多用户、多组织、角色权限。
- Agent 自动执行和效果复盘闭环。
- PostgreSQL 完整生产化部署。

待客户环境确认：

- 实际域名、HTTPS、CORS。
- Meta OAuth Redirect URI。
- 客户 Meta App ID / App Secret。

- SQLite 备份路径或 PostgreSQL 连接。

## 5. 已知限制

- v0.1 当前只把 Meta 作为真实平台链路。
- Google/TikTok 在前端标注为待接入，不作为可用真实链路。
- Agent 行动队列是规则版建议，不自动执行预算或平台操作。
- Demo Mode 固定用户仅用于 POC，不用于生产多人协作。
- SQLite 适合演示和短期 POC；试生产建议 PostgreSQL。
- 前端仍保留若干历史页面类型治理技术债，详见 `docs/16-v0.1技术债与后续修复清单.md`。
