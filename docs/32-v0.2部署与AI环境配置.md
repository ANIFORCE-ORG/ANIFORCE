## 2. AI Provider 策略

交付演示默认：

```env
AI_PROVIDER=mock
```

原因：

- 演示结果稳定。
- 不依赖外部模型网络。
- 不产生真实模型费用。
- 仍会写入 usage log 和 AI output，保留审计链路。

真实模型接入：

```env
AI_PROVIDER=openai
OPENAI_API_KEY=sk-...
AI_SMALL_MODEL=
AI_MEDIUM_MODEL=
AI_LARGE_MODEL=
```

当前代码已预留 provider 边界，下一步只替换 provider 实现，不改变前端入口。

## 3. 数据库迁移

进入后端目录执行：

```bash
venv/bin/alembic upgrade head
```

本次新增表：

- `campaign_materials`
- `ai_usage_logs`
- `ai_outputs`
- `ai_budgets`

## 4. 启动方式

后端：

```bash
cd backend
venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8010
```

前端：

```bash
cd frontend/packages/main-app
pnpm run dev
```
