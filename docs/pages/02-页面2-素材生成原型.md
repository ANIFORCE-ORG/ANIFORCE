## 对话式交互设计要点

### 1. 实时进度反馈

**分阶段展示生成进度**:
```
0% → 30% (A段完成)
  ↓
30% → 40% (B段等待)
  ↓
40% → 70% (C段完成)
  ↓
70% → 100% (拼装完成)
```

**每阶段都有AI消息**:
- ✓ "正在生成A段..."
- ⏳ "B段需要您上传素材..."
- ✓ "正在生成C段..."
- ✓ "正在自动拼装..."

### 2. 游戏专业术语

**使用游戏行业熟悉的术语**:
- Boss战、CTA、CTR、CVR
- Meta Nobid、Reels、Stories
- ABC三段式、钩子、玩法

**素材卡片展示**:
- ✅ 选中标记（绿色勾）
- ⭐ CTR星级评分
- 🏷️ 快速识别标签
- 👁️ 查看次数统计

### 4. 智能推荐

**AI主动建议**:

- 风险评估
