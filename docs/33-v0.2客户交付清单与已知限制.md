# v0.2 客户交付清单与已知限制

- 登录 Demo 模式。
- 项目管理。
- 项目绑定 Meta 广告账户。
- 项目下创建广告计划。
- 批量创建计划后端接口。
- 计划-素材绑定元数据。

- 构建和后端编译验证。

## 2. 已知限制

- 当前真实平台执行仅覆盖 Meta 沙盒/测试链路。
- Google/TikTok 显示为待接入，不作为本轮真实创建渠道。
- AI Provider 当前默认 mock，真实 OpenAI Provider 需要后续补实现。
- 旧计划只有 `material_ids`，没有历史绑定标题/描述；新建计划具备完整绑定元数据。
- 创建计划页面业务已接入新流程，但视觉仍是 4 步；Day 6 后续可压缩成原型的 3 步表达。
- 客户级账单系统暂未纳入。
- 自动执行预算调整暂未纳入，AI 建议必须人工确认。

## 4. v0.2 验收标准

交付给客户前必须确认：

- `pnpm run build` 通过。
- `python3 -m compileall backend/app` 通过。
- `/health` 正常。
- 项目工作台可打开。
- 可从项目创建计划。
- 可保存计划素材标题/描述。
- 可上传合法投放结果。
- 超预算投放结果会被拒绝。
- AI usage summary/logs 可查询。
