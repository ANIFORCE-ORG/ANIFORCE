## 3. 推荐部署拓扑

```
Browser
  |
  | HTTPS 443
  v
Reverse Proxy
  |--------------------|
  | /                  | /api/v1, /health
  v                    v
Frontend               FastAPI Backend
                       |
                       v
                SQLite or PostgreSQL
```

POC 环境可以使用 SQLite。

客户试生产或多人使用环境建议使用 PostgreSQL。

## 10. 备份与恢复

POC SQLite：

1. 停止后端服务。
2. 复制 SQLite 数据库文件到备份目录。
3. 重启后端服务。

恢复：

1. 停止后端服务。
2. 用备份文件覆盖当前数据库文件。
3. 重启后端服务。
4. 跑健康检查。

PostgreSQL：

1. 每日定时 `pg_dump`。
2. 保留 7 天。
3. 恢复前先备份当前库。
4. 恢复后跑迁移和健康检查。
