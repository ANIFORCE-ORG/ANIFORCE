# 权限与账号模式说明 v0.1

## 1. 目标

明确 v0.1 Customer Preview 的账号、权限、认证边界，避免客户把 Demo Mode 误解为生产权限体系。

## 2. 两种运行模式

### 2.1 POC Demo Mode

配置：

```bash
DEMO_MODE=true
```

行为：

- 后端返回固定用户。
- 适合客户演示、内部 POC、功能验证。
- 不需要真实登录即可访问演示数据。
- 所有演示数据归属于固定用户。

优点：

- 部署简单。
- 演示稳定。
- 不依赖客户组织和账号体系。

限制：

- 不适合生产。
- 不提供真实多用户隔离。
- 不适合多人长期使用。
- 不应接入真实生产广告预算执行。

适用场景：

- v0.1 客户预览。
- 销售演示。
- 单客户短期试用。

### 2.2 Customer Trial JWT Mode

配置：

```bash
DEMO_MODE=false
JWT_SECRET=strong-random-secret
JWT_ALGORITHM=HS256
```

行为：

- 用户必须登录。
- API 通过 Bearer Token 鉴权。
- 项目、账户、素材、Campaign 按用户隔离。

适用场景：

- 客户试生产。
- 多人试用。
- 真实项目数据。

最低要求：

- 管理员账号。
- 强 JWT Secret。
- HTTPS。
- 精确 CORS。
- 不使用默认密码。

## 3. v0.1 推荐交付策略

默认：

- 客户演示使用 POC Demo Mode。
- 文档明确 Demo Mode 不等于生产权限系统。
- 如果客户要求试用账号，再切换 Customer Trial JWT Mode。

不建议：

- 在 Demo Mode 下接入真实生产预算。
- 在 HTTP 明文环境传输 Token。
- 把平台 App Secret 写入前端或文档。

## 4. 账号清单模板

### 4.1 POC Demo Mode

| 账号 | 用途 | 权限 | 交付方式 |
|---|---|---|---|
| Demo 固定用户 | 客户演示 | 全部演示数据 | 不单独交付密码 |

### 4.2 Customer Trial JWT Mode

| 账号 | 角色 | 权限 | 交付方式 |
|---|---|---|---|
| admin | 管理员 | 系统配置、平台连接、全部项目 | 密码管理器 |
| operator | 投放人员 | 项目、素材、Campaign 操作 | 密码管理器 |
| viewer | 观察者 | 报表和项目只读 | 密码管理器 |

## 5. 角色权限规划

v0.1 最低边界：

| 能力 | Demo 固定用户 | admin | operator | viewer |
|---|---:|---:|---:|---:|
| 查看 Dashboard | 是 | 是 | 是 | 是 |
| 查看项目 | 是 | 是 | 是 | 是 |
| 创建/编辑项目 | 是 | 是 | 是 | 否 |
| 查看广告账户 | 是 | 是 | 是 | 是 |
| 配置平台连接 | 是 | 是 | 否 | 否 |
| 创建 Campaign | 是 | 是 | 是 | 否 |
| 查看素材 | 是 | 是 | 是 | 是 |
| 上传素材 | 是 | 是 | 是 | 否 |
| 查看报表 | 是 | 是 | 是 | 是 |
| 确认 Agent 建议 | 是 | 是 | 是 | 否 |
| 删除/断开账户 | 是 | 是 | 否 | 否 |

说明：

- 当前 v0.1 代码不一定已完整实现 admin/operator/viewer 三角色。
- 如果本周交付使用 Demo Mode，角色表作为 v0.2 权限规划。
- 如果客户试用要求角色隔离，需要单独列为 P0 加固项。

## 6. 敏感操作

以下操作必须在客户环境谨慎处理：

- 保存 Meta App Secret。
- 导入平台 Access Token。
- 断开广告账户。
- 创建真实 Meta Campaign。
- 后续版本中的预算调整、暂停、启用、删除广告。
- 数据库重置。
- 备份覆盖。

v0.1 建议：

- 真实创建 Campaign 默认使用 `PAUSED` 状态。
- 不自动启动投放。
- 不自动消耗预算。
- Agent 建议只做人工确认，不自动执行真实平台变更。

## 7. 安全要求

必须：

- `JWT_SECRET` 使用强随机值。
- `.env` 不提交 Git。
- `META_APP_SECRET` 不写前端。
- Token 不进入日志。
- 生产环境使用 HTTPS。
- CORS 配置为明确域名。

禁止：

- 客户生产环境使用默认弱密钥。
- 在客户文档中明文写生产密码。
- 在 Demo Mode 下宣称具备生产级权限隔离。
