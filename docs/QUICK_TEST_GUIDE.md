## ⚠️ 可能的问题

### 问题 1：右侧没有 AI 助手面板

**解决**：
- 检查是否登录成功
- 刷新页面
- 查看浏览器控制台（F12）是否有错误

### 问题 2：输入框无法输入

**解决**：
- 检查是否有加载错误
- 打开控制台查看 Network 请求
- 重启前端：
  ```bash
  pkill -f "vite.*13003"
  cd frontend && pnpm --filter main-app dev --host 127.0.0.1 --port 13003
  ```

### 问题 3：发送后无响应

**解决**：
- 打开控制台（F12）→ Network tab
- 查看是否有请求发出
- 检查后端日志：`tail -f logs/backend-dev.log`

### 问题 4：Plan 不显示

**可能原因**：
- Agent 判断任务太简单
- 尝试更复杂的查询

## 🐛 调试方法

### 浏览器控制台（F12）

1. **Console tab** - 查看 JavaScript 错误
2. **Network tab** - 查看 API 请求
   - 找到 `/api/v1/agent/chat/sessions/.../stream`
   - 查看 EventStream 事件
3. **Vue DevTools** - 检查组件状态（如果安装）

### 后端日志

```bash
# 实时查看
tail -f logs/backend-dev.log

# 过滤 Plan 相关
tail -f logs/backend-dev.log | grep -i "plan\|todo"

# 过滤错误
tail -f logs/backend-dev.log | grep -i "error\|exception"
```

### 前端日志

```bash
tail -f /tmp/frontend-new.log
```
