## Slide 3: Pain Points

English title:

```text
PAIN POINTS
```

Chinese title:

```text
传统效果广告进入双重瓶颈
```

Three pains:

```text
01 素材生命周期极短
优质素材仅维持 3-5 天热度，高频买量团队需要持续生产、测试、替换素材。

02 投放系统被平台黑盒化
Google / Meta / TikTok 越来越自动化，但广告主缺少跨平台策略、素材理解和预算调度能力。

03 新流量入口正在变化
用户开始通过 Chatbot、AI Search、个人 Agent 获取信息和做决策，传统广告资产难以被 Agent 理解、引用和验证。
```

Case highlight:

```text
内容型行业是最先被冲击的高频广告市场：游戏、短剧、社交、泛娱乐。
```
