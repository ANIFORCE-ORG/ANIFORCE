# Agent Ads OS

This project stores the May 1, 2026 discussion notes about agent-native advertising and how ANIFORCE could evolve from RTC ad automation into an agent-era advertising operating system.

## Core Thesis

Future advertising will split into two systems:

- Attention Ads: ads shown to humans, optimized for attention, emotion, and brand memory.
- Intent Ads: ads exposed to user agents, optimized for intent matching, trust, utility, and executable actions.

The opportunity is not to replace Google, Meta, or TikTok immediately. The opportunity is to build a neutral advertiser-side and cross-platform layer that makes products, offers, evidence, creatives, and actions readable, verifiable, comparable, and executable by agents.

## Strategic Position

ANIFORCE should not be positioned as only an AI creative generation tool.

Recommended positioning:

> ANIFORCE is the advertising operating system for the agent era. It helps advertisers transform products, creatives, offers, proof, and media-buying strategies into agent-readable, verifiable, executable, and optimizable growth assets.

## Continuation Prompt

When continuing this work, start from:

1. Agent ads are not just ads "seen by agents"; they are structured commercial objects.
2. The ranking system must optimize user utility first, then commercial value within trust boundaries.
3. Google/Meta/TikTok are execution channels in the short term, not the whole product surface.
4. ANIFORCE's wedge should be game/short-drama/high-frequency performance marketing teams.
5. The long-term platform is Agent Ads OS plus Agent Ad Exchange.
6. The practical wedge is GEO plus human ad automation: every human-facing campaign should also emit agent-readable, chatbot-searchable offer assets.
