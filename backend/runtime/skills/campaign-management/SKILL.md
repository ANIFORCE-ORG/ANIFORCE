# 广告计划管理 Skill

## 目标
帮助用户管理广告计划的全生命周期，包括创建、查询、更新、删除、暂停和启动广告计划。

## 输入
- 用户自然语言需求（如"为项目 A 创建 Facebook 广告，预算 2 万"）
- 广告计划 ID（用于查询/更新/删除）
- 广告计划参数（名称、平台、预算、目标人群等）

## 输出
- 结构化广告计划信息
- 操作确认消息
- 效果分析报告（如需要）
- 错误提示（如操作失败）

## 可用的 MCP Tools

### 1. list_campaigns
查询广告计划列表

**参数**：
- `project_id` (string, 可选): 项目 ID，如果提供则只返回该项目的广告计划

**返回**：广告计划列表

### 2. create_campaign
创建新广告计划

**参数**：
- `project_id` (string, 必填): 所属项目 ID
- `name` (string, 必填): 广告计划名称
- `platform` (string, 必填): 投放平台（如 "facebook", "google", "tiktok"）
- `budget` (number, 必填): 预算金额，必须 > 0
- `target_audience` (string, 可选): 目标人群
- `start_date` (string, 可选): 开始日期
- `end_date` (string, 可选): 结束日期

**返回**：创建的广告计划对象

### 3. get_campaign_detail
查询广告计划详情

**参数**：
- `id` (string, 必填): 广告计划 ID

**返回**：广告计划详细信息

### 4. update_campaign
更新广告计划

**参数**：
- `id` (string, 必填): 广告计划 ID
- `name` (string, 可选): 新名称
- `budget` (number, 可选): 新预算
- `status` (string, 可选): 新状态（"active", "paused", "completed"）
- 其他可选字段...

**返回**：更新后的广告计划对象

### 5. delete_campaign
删除广告计划

**参数**：
- `id` (string, 必填): 广告计划 ID

**返回**：删除确认消息

## 工作流

### 工作流 1：创建广告计划

**触发条件**：
- 用户说"创建广告计划"
- 用户说"为项目 X 新建广告"
- 用户说"投放 Facebook 广告"

**步骤**：
1. **确定所属项目**
   - 如果用户提到项目名称，查找项目 ID
   - 如果用户没说，询问或使用当前上下文的项目

2. **提取广告计划信息**
   - 名称（必填）
   - 平台（必填）
   - 预算（必填）
   - 目标人群（可选）
   - 投放时间（可选）

3. **验证参数**
   - 项目必须存在
   - 预算必须 > 0
   - 平台必须是支持的平台

4. **调用 MCP Tool**
   ```
   调用: create_campaign(project_id="...", name="...", ...)
   ```

5. **返回结果**

**示例对话**：

```
用户: "为 RPG 游戏项目创建一个 Facebook 广告，预算 2 万，目标人群是 18-35 岁男性游戏玩家"

AI: [使用 campaign-management Skill]
    好的，我来帮您创建广告计划。
    
    [查找项目]
    项目: RPG 游戏项目 (proj_abc123) ✓
    
    [调用 create_campaign]
    广告计划信息：
    - 名称: Facebook 广告
    - 平台: Facebook
    - 预算: ¥20,000
    - 目标人群: 18-35岁男性游戏玩家
    - 所属项目: RPG 游戏项目
    
    ✅ 已创建广告计划 "Facebook 广告"（ID: camp_xyz789）
    
    广告计划已创建，您可以：
    - 查看广告计划详情
    - 修改预算或目标人群
    - 暂停或启动广告
```

### 工作流 4：更新广告计划

**触发条件**：
- 用户说"修改广告计划 X"
- 用户说"增加 Facebook 广告的预算"
- 用户说"把广告计划 X 的预算改成 Y"

**步骤**：
1. **识别广告计划和修改内容**

2. **获取当前信息**
   ```
   调用: get_campaign_detail(id="...")
   ```

3. **调用更新**
   ```
   调用: update_campaign(id="...", budget=新预算)
   ```

4. **返回结果**
   - 显示修改对比

**示例对话**：

```
用户: "把 Facebook 广告的预算增加到 3 万"

AI: [使用 campaign-management Skill]
    [获取当前信息]
    当前预算: ¥20,000
    
    [调用 update_campaign(id="camp_001", budget=30000)]
    
    ✅ 已更新广告计划预算：
    - 广告计划: Facebook 广告
    - 原预算: ¥20,000
    - 新预算: ¥30,000
    - 增加: ¥10,000 (+50%)
```

### 工作流 5：暂停/启动广告计划

**触发条件**：
- 用户说"暂停广告计划 X"
- 用户说"启动广告计划 X"
- 用户说"停止 Facebook 广告"

**步骤**：
1. **识别广告计划和操作**

2. **调用更新（修改 status）**
   ```
   调用: update_campaign(id="...", status="paused" 或 "active")
   ```

3. **返回结果**

**示例对话**：

```
用户: "暂停 Instagram 广告"

AI: [使用 campaign-management Skill]
    [调用 update_campaign(id="camp_004", status="paused")]
    
    ⏸️ 已暂停广告计划：
    - 广告计划: Instagram 广告
    - 状态: 进行中 → 已暂停
    
    暂停后：
    - 广告将停止投放
    - 预算将被保留
    - 可随时重新启动
```

### 工作流 6：删除广告计划（中等风险）

**触发条件**：
- 用户说"删除广告计划 X"

**步骤**：
1. **获取广告计划详情**
   ```
   调用: get_campaign_detail(id="...")
   ```

2. **展示警告**
   - 说明删除后无法恢复
   - 展示广告计划信息

3. **要求确认**
   - 要求用户回复确认语句

4. **验证并执行**
   ```
   调用: delete_campaign(id="...")
   ```

**示例对话**：

```

    - 名称: 测试广告

    - 平台: Facebook
    - 预算: ¥5,000
    - 状态: 已暂停
    
    ⚠️ 此操作不可逆！
    
    如果确认删除，请回复：**"确认删除测试广告"**
```

## 硬约束

1. 广告计划必须属于某个项目（project_id 必填）
2. 预算必须 > 0
3. 广告计划名称不能为空
4. 删除操作必须要求确认
5. 暂停/启动操作必须验证当前状态
6. 不要修改用户没有要求修改的字段

**禁止**：
- ❌ 不要在没有确认的情况下删除广告计划
- ❌ 不要假装操作成功
- ❌ 不要创建没有项目的广告计划

## 错误处理

### 错误 1：项目不存在
```
用户: "为项目 XXX 创建广告"

AI: ❌ 找不到项目 "XXX"
    
    您的项目列表：
    [显示项目列表]
    
    请选择一个项目，或先创建新项目。
```

### 错误 2：广告计划不存在
```
用户: "查看广告 ABC"

AI: ❌ 找不到广告计划 "ABC"
    
    您的广告计划：
    [显示广告计划列表]
```

---

## 注意事项

1. **智能关联项目**
   - 优先使用用户当前上下文的项目
   - 如果不明确，询问用户

2. **平台识别**
   - 支持多种平台名称（如"Facebook"、"fb"、"脸书"都能识别）

3. **状态管理**
   - 已完成的广告计划不应该被暂停或启动
   - 已删除的广告计划无法恢复

4. **实时反馈**
   - 操作前告知用户
   - 操作后明确确认
