# 数据分析 Skill

## 目标
帮助用户分析项目和广告计划的数据表现，生成可视化报告和优化建议。

## 输入
- 用户分析需求（如"分析项目 A 的数据"）
- 项目 ID 或广告计划 ID
- 分析维度（预算、效果、趋势等）

## 输出
- 数据摘要
- 关键指标分析
- 可视化数据（文字描述或表格）
- 优化建议

## 可用的 MCP Tools

本 Skill 主要使用以下 MCP Tools 获取数据：

### 1. get_project_detail
获取项目详细数据

### 2. get_campaign_detail
获取广告计划详细数据

### 3. list_campaigns
获取广告计划列表（用于批量分析）

**注意**：当前版本没有专门的数据分析 API，我们通过组合使用上述 Tools 来进行数据分析。未来可能会添加专门的数据分析 Tools。

## 工作流

### 工作流 1：项目整体数据分析

**触发条件**：
- 用户说"分析项目 X"
- 用户说"项目 X 的数据怎么样"
- 用户说"给我看看项目表现"

**步骤**：
1. **获取项目数据**
   ```
   调用: get_project_detail(id="...")
   ```

2. **获取所有广告计划数据**
   ```
   调用: list_campaigns(project_id="...")
   对每个广告计划: get_campaign_detail(id="...")
   ```

3. **计算关键指标**
   - 预算总额 vs 实际花费
   - 预算使用率
   - 广告计划数量和状态分布
   - 平均效果指标（如有）

4. **生成分析报告**
   - 总体概况
   - 预算分布
   - 效果对比
   - 优化建议

**示例对话**：

```
用户: "帮我分析一下 RPG 游戏项目的整体数据"

### 工作流 2：单个广告计划深度分析

**触发条件**：
- 用户说"详细分析 Facebook 广告"
- 用户说"深入分析广告 X 的数据"

**步骤**：
1. **获取广告计划数据**
   ```
   调用: get_campaign_detail(id="...")
   ```

2. **多维度分析**
   - 预算执行情况
   - 效果指标分析
   - 与项目其他广告计划对比
   - 趋势分析（如有历史数据）

3. **生成深度报告**

**示例对话**：

```
用户: "详细分析 Facebook 广告的表现"

AI: [使用 data-analysis Skill]
    [调用 get_campaign_detail]
    [调用其他广告计划数据用于对比]
    
    📊 **Facebook 广告** 深度分析
    
    ## 基本信息
    - 投放平台: Facebook
    - 所属项目: RPG 游戏项目
    - 创建时间: 2025-06-10
    - 运行天数: 3 天
    - 当前状态: 进行中 ✅
    
    ---
    
    ## 预算分析
    
    **预算执行**
    - 总预算: ¥20,000
    - 已花费: ¥8,500 (42.5%)
    - 剩余: ¥11,500 (57.5%)
    - 日均花费: ¥2,833
    - 预计耗尽时间: 4 天后
    
    **预算节奏**
    ✅ 花费节奏合理，预计在计划时间内完成
    
    ---
    
    ## 效果分析
    
    **核心指标**
    - 曝光量: 150,000
    - 点击量: 4,500
    - 转化量: 450
    - CTR: 3.0%
    - 转化率: 10.0%
    - CPA: ¥18.9
    
    **与项目平均对比**
    - CTR: 3.0% vs 项目平均 3.3% ⚠️ 略低
    - 转化率: 10.0% vs 项目平均 9.0% ✅ 优秀
    - CPA: ¥18.9 vs 项目平均 ¥19.2 ✅ 良好
    
    **优势**：
    ✅ 转化率高，说明用户质量好
    ✅ CPA 低于平均，成本控制好
    
    **改进空间**：
    💡 CTR 略低，可以优化广告创意或定向
    
    ---
    
    ## 目标受众分析
    
    **当前设置**
    - 目标人群: 18-35岁男性游戏玩家
    - 投放地区: 中国大陆
    
    **建议**：
    💡 可以尝试扩展到：

       - 目标: 提升 CTR 至 3.5%+
       - 方法: A/B 测试不同的图片和文案

       - 调整出价策略

    - CTR 有提升空间

## 硬约束

1. **数据真实性**
   - 只分析真实数据，不能编造
   - 如果某个指标没有数据，明确说明
   - 如果 API 不支持某种分析，诚实告知

2. **建议可行性**
   - 建议必须基于数据
   - 建议必须可执行
   - 说明预期效果和风险

3. **表达清晰**
   - 使用可视化表格
   - 用 emoji 增强可读性
   - 避免专业术语堆砌

**禁止**：
- ❌ 不要编造数据
- ❌ 不要给出无法验证的结论
- ❌ 不要过度承诺效果

---

## 注意事项

1. **当前版本限制**
   - 没有专门的数据分析 API
   - 需要组合使用多个 MCP Tools
   - 没有历史数据（趋势分析受限）
   - 没有预测模型

2. **未来功能**
   - 历史数据趋势
   - 预测模型
   - 竞品对比
   - 自动化优化建议

3. **数据处理**
   - 需要调用多个 API 获取完整数据
   - 计算派生指标（CTR、转化率等）
   - 数据对比和排名

4. **报告生成**
   - 使用表格展示数据
   - 使用 emoji 标记重点
   - 分层次展示（总结 → 详情 → 建议）
