✨ 核心改进总结

check_circle 移除 AI 特征

去掉侧边 3px 粗条纹、18px 圆角、渐变背景等典型 AI 生成界面标志。

check_circle 统一色彩系统

主色统一为 #137fec，成功绿 #10b981，错误红 #ef4444，不再混用多种蓝色。

check_circle 移除装饰效果

去掉 backdrop-filter 毛玻璃、双层阴影、transform 动画等装饰性效果。

check_circle 减少视觉噪音

移除状态点脉动动画，只保留必要的状态指示，降低认知负担。

check_circle 无障碍支持

添加 @media (prefers-reduced-motion: reduce)，尊重用户的动效偏好设置。

check_circle 性能优化

移除 GPU 密集的 backdrop-filter，减少不必要的动画，提升渲染性能。
